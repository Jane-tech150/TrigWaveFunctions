# TrigWaveFunctions
Mathematical wave visualization in Python. Plotting sine, cosine, and tangent functions with LaTeX labels, and graph formatting using NumPy and Matplotlib.

# Trigonometric Functions Visualizer
The project demonstrates the behavior of sine, cosine, and tangent graphs using smooth plotting over a full 2π range and mathematical formatting.

# What This Shows
- Periodic nature of sin and cos
- Tangent discontinuities handled using NaN masking
- Proper radian axis labels using LaTeX formatting

# Libraries Used
- NumPy
- Matplotlib

## What I Learned
- How to use NumPy to generate continuous x-values for smooth mathematical plotting
- How Matplotlib functions work for creating, customizing, and styling graphs
- Visualization of sine, cosine, and tangent functions over a trigonometric interval
- How changing y-values affects wave behavior, amplitude, and graph appearance
- Using LaTeX formatting for mathematical axis labels and symbols
- Handling tangent discontinuities using NaN masking to avoid incorrect vertical lines at asymptotes
- Improving graph readability using grids, labels, legends, and custom tick formatting
